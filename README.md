# 📈 Sistema Executivo de Gestão & Planejamento Financeiro

Aplicação web para controle patrimonial, gestão de repasses, conciliação mensal e simulação de renda fixa.

## 🚀 Tecnologias Utilizadas
- **HTML5** (Estrutura semântica)
- **CSS3** (Design System com CSS Variables e Dark Theme)
- **JavaScript ES6+** (Persistência via localStorage e integração via Fetch API com o BCB)

## 📌 Funcionalidades
- Checklist interativo de repasses mensais com anexos e notas.
- Simulação de CDB/LC vs. LCI/LCA com atualização automática da taxa CDI pelo Banco Central.
- Importador inteligente de contas em formato texto/bloco de notas.
- Gráficos nativos em SVG (Linha e Pizza) para acompanhamento da trajetória patrimonial.
